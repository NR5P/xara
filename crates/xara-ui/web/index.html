    Settings

    Empty fields use the command line (shown greyed). xara restarts only while idle, which takes a few seconds; if saved settings fail to start, it falls back to the command line and says so here.

    Registered is for a user with a registered copy of VARA: links with other registered stations run at full speed. Audio delay is the round trip in the audio path that xara does not add itself, such as network audio (two phones on their own speakers: about 500); leave it at 0 for a radio on a USB interface.

    Showing other stations' traffic decodes VARA HF links between other stations, like VARA's monitor, and prints them with your own links' text to xara's output (journalctl -u xara@STATION -f for the system service). Answering stations show as #hash unless their call is listed, separated by spaces. Every packet lists each frame heard.

    Recording saves what the modem hears and sends (about 3 MB a minute); the debug log adds a timestamped line for every frame, host command and, once a second, the audio levels. Both go next to the settings file.
